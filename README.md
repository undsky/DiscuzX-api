1. 安装 [小云插件](https://addon.dismall.com/plugins/appbyme_app.html)

1. 将mobcent接口包上传到 Discuz 根目录
2. 访问链接 <http://你的论坛网址/mobcent/requirements/index.php> 确保服务器的环境符合插件要求
